Finding (tools, first install for real): the launcher's fence decided two things the specification had not. Deno cannot create a symlink unless it may read and write everywhere, so copying the mCRL2 app bundle out of its image — full of framework symlinks — failed inside the fence that grants naima tools only its own directory; the bundle is now copied by ditto, macOS's own copier, a program the grant may run. And a command started by naima run inherits NAIMA_LAUNCHED, so the test suite run that way failed eight tests that start Naima themselves (filed as a bug). With both settled, mCRL2 202607.0 and Storm (stormpy 1.14.0 on a shipped CPython 3.13.16) installed through the real launcher into a scratch directory, and the mCRL2 verifier proved a property with PATH stripped, using only the installed toolset. 11 tests, on Deno, Node and Bun; no real download in any of them.
