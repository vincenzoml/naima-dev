Finding (long work, first command working): naima run and naima wait work end to end through the real launcher — a supervisor per run, started detached, outlives the naima that started it, writes a heartbeat, and ends the whole process group at the time budget (a background child included) or when the declared paths outgrow the disk budget; wait reads only the record and returns at its timeout saying the run still runs. The launcher had to grant run and wait alone the right to start Deno and ssh and to hand the command the whole environment: the permission fence that keeps every other command from running programs is what made a dedicated grant, rather than a general one, the right shape. 18 tests, on the run, wait, list, clean, remote, rule and check paths.
