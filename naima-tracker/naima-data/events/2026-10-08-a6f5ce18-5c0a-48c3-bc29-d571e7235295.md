Finding (long work, rule active): the rule that long work goes through naima run and naima wait is now shipped with Naima itself, active for agents in every project that loads it, rather than offered as a template a project may adopt — the incident happened in a project that had added no such rule, so an opt-in rule would not have prevented it. To ship a rule, the rules plugin gained a point other plugins contribute to and a retire option, so a project that declines it says so visibly in one place. It is enforced where Naima can see: the check wait-loops reports a hand-written wait in a tracked shell script as a problem, and in a session note — never rewritten — as a note. All 431 tests pass on Deno, Node and Bun on macOS; eight of the nine requirements are met, the ninth (Windows, Linux) awaits a run on those machines.
