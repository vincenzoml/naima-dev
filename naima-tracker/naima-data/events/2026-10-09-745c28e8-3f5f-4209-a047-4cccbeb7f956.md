Finding (tools, specification): the artefacts decide the shape. mCRL2 202607.0 publishes a .dmg per Mac architecture, a .zip for Windows, and for Linux only system packages (.deb, .rpm) and nothing for arm64; its Linux programs find their libraries through $ORIGIN/../lib, so the .deb can be unpacked into Naima's directory without dpkg or root, at the price of needing glibc 2.38. The macOS image asks to accept its licence (BSL-1.0) before it mounts, so the consent Naima asks must name the licence. stormpy 1.14.0 ships wheels for macOS and Linux only, for Python 3.10 and later, while macOS's own python3 is 3.9: Storm cannot be portable without Naima shipping the Python too, so a Python runtime becomes a tool like any other. Specification and nine requirements written before any code: specs/tools-plugin-declares-tools-needs-naima-tools.
