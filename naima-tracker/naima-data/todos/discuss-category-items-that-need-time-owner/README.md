# A "to discuss" category

Owner, 2026-10-07 (VoxLogicA-2-clean): some decisions and reviews need time together, not a quick answer; they must be marked as such, gathered, and a meeting fixed.

Today it is done with `tags=discussion` and a hand-written agenda todo; nothing lists them, orders them, or ties them to a meeting.

Proposal (specify first): a `discuss` mark on any item (with the time it needs); `naima agenda` lists marked items, most consequential first, with the context to read before; a meeting is a dated item (or gate) the agenda items are attached to; after it, each item records its decision or next step and leaves the agenda.
