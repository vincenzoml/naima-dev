# naima verify, metrics run and tools install report their progress: mCRL2 stages with states and BES equations, metrics done of total, bytes downloaded

Specification: specs/progress-long-work-says-how-far, section 6.

Checked by: the core reporter writes one structured line to $NAIMA_RUN_PROGRESS at each stage and is silent on standard error for its first 2 seconds; naima verify on the mCRL2 verifier reports each tool as a stage of its property, with the states explored by lps2lts and the BES equations generated by pbessolve read from their --verbose output, those counting lines left out of the kept output; metrics run reports the metrics taken of the total; tools install reports the bytes downloaded of the declared size.

Why: Naima's own long commands are the first that must keep the rule it ships (specification §0, §1).
