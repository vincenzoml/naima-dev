# naima tools install shows source, size and licence and goes on only with consent: a yes on a terminal, or --consent and --by, recorded in the receipt

Specification: specs/tools-plugin-declares-tools-needs-naima-tools, section 4.

Checked by: without a terminal and without --consent the install refuses, printing the plan, and fetches nothing; a no at the prompt fetches nothing; with --consent and --by the receipt holds the words, who, how and when.

Why: the owner's decision that Naima installs only with the owner's consent, and the privacy of the owner's words: what is recorded is the yes, restated (§4).
